# Tayana Academy – Approved Course Catalogue

Use only the following six programs and curriculum facts in candidate conversations.

| Program | Approved curriculum |
|---|---|
| AI Engineering | LLMs, Prompt Engineering, RAG, AI App Development, Agents |
| Pro Code Agentic Engineering | LangChain, LangGraph, CrewAI, OpenAI Agents SDK |
| Low Code Agentic Engineering | Workflow Automation, n8n, Enterprise Low-Code Agentic Systems |
| ML Engineering | ML Foundations, Model Training, Scikit-Learn, PyTorch, MLOps |
| Python Programming | Core Python, OOP, Data Structures, Applied Automation Scripting |
| Full Stack MERN Development | MongoDB, Express.js, React.js, Node.js, REST APIs |

## High-level guidance (not a guarantee)
- Candidates needing programming foundations may explore Python Programming.
- Candidates interested in LLM applications, RAG, and AI applications may explore AI Engineering.
- Candidates interested in code-first agent frameworks may explore Pro Code Agentic Engineering.
- Candidates interested in workflow automation and low-code enterprise systems may explore Low Code Agentic Engineering.
- Candidates focused on machine-learning foundations, training, and MLOps may explore ML Engineering.
- Candidates interested in full-stack JavaScript web development may explore Full Stack MERN Development.

## Missing-information rule
Exact tuition fees, discounts, batch start dates, course duration, placement metrics, certificate recognition, EMI/scholarship availability, hostel/food facilities, and other unlisted claims are not approved by this source.

If asked for unverified commercial or operational information, say:
"I don't have the confirmed schedule and fee details for that specific batch right now. I can arrange for an Admissions Counsellor to share the official fee schedule with you. Would you like me to connect you?"

Never promise 100% placement or a specific job/employer outcome.
